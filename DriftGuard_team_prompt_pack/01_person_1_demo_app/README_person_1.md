# Person 1 — Demo SaaS App + Design System

## Mission

Build the product surface judges see first.

Your job is to make DriftGuard feel necessary by creating a believable, polished SaaS billing page with exactly one intentional design drift block.

## Owns

```txt
apps/demo-saas
tokens.json
Button component
Card component
Billing dashboard
Intentional drift block
Clean before/after visual
```

## Start here

1. Paste `prompt_01_build_demo_saas.md` into Cursor.
2. Run the demo app.
3. Paste `prompt_02_polish_ui.md` if the page looks too basic.
4. Use `technical_guide.md` to verify structure.
5. Use `acceptance_checklist.md` before handoff.

## What not to do

Do not add auth, database, Supabase, or complex product flows.

The app needs to look great, not be a full SaaS.
