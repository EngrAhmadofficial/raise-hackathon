# Team Protocol

## Every 45 minutes

Each person answers:

```txt
1. What works right now?
2. What file did I change?
3. What is blocking integration?
4. What can be demoed if I stop now?
```

## Merge order

```txt
1. Person 1: demo app
2. Person 4: report UI with mock findings
3. Person 2: scanner
4. Person 3: patcher
5. Person 5: extension + docs
```

## Code freeze

Stop building features before final submission. Spend the last block rehearsing.

## Demo machine

One person owns the final machine. No last-minute dependency upgrades on that machine.
